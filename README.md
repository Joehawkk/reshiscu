# Решение задачи №6 — Турнир «Решис!» | Финал. Бизнес и аналитика

Задача: найти 1–2 пользователей в социальной сети, с которыми выгоднее всего заключить рекламный контракт, чтобы максимизировать прибыль в рамках бюджета.

---

## Условие задачи

Компания хочет запустить вирусную рекламу в социальной сети из 63 пользователей. Пользователь начинает использовать продукт, если это уже сделали **≥ 20% его знакомых**. Нужно выбрать 1–2 человека для рекламного контракта так, чтобы итоговая прибыль была максимальной.

Параметры:

| Параметр | Значение |
|----------|----------|
| Бюджет | 5 000 ₽ |
| Доход с одного активного пользователя | 500 ₽ |
| Стоимость контракта с пользователем | 200 ₽ × количество связей |
| Порог активации | 20% активных соседей |

---

## Решение

Алгоритм перебирает все одиночные вершины и все пары, для каждой запускает симуляцию распространения по правилу 20% и выбирает вариант с максимальной прибылью.

```
Дано: начальное множество seed-пользователей

Повторять пока есть изменения:
    Для каждого неактивного пользователя v:
        Если (активных соседей / всего соседей) >= 0.2:
            активировать v

Вернуть количество активных пользователей
```

---

## Запуск

```bash
python main.py
```

```
Заключим рекламные контракты с пользователями: X, Y

```
