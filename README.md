# Viral Marketing — оптимизация рекламного охвата

Задача: найти 1–2 пользователей в социальной сети, с которыми выгоднее всего заключить рекламный контракт, чтобы максимизировать прибыль в рамках бюджета.

---

## Как это работает

Модель основана на **пороговом правиле 20%**: пользователь начинает использовать продукт, если это уже сделали ≥ 20% его связей в сети.

1. Граф из 63 пользователей загружается из CSV-матрицы смежности
2. Для каждой одиночной вершины и каждой пары вершин считается стоимость рекламы
3. Если стоимость вписывается в бюджет — запускается симуляция распространения
4. Выбирается вариант с наибольшей итоговой прибылью

---

## Параметры

| Параметр | Значение |
|----------|----------|
| Бюджет | 5 000 ₽ |
| Доход с одного активного пользователя | 500 ₽ |
| Стоимость контракта с пользователем | 200 ₽ × количество связей |
| Порог активации | 20% активных соседей |

---

## Алгоритм распространения

```
Дано: начальное множество seed-пользователей

Повторять пока есть изменения:
    Для каждого неактивного пользователя v:
        Если (активных соседей / всего соседей) >= 0.2:
            активировать v

Вернуть количество активных пользователей
```

Перебираются все одиночные вершины и все пары — итого O(n²) симуляций.

---


## Входные данные

`graphcuu.csv` — матрица смежности 63×63, разделитель `;`.  
Строка `i`, столбец `j` содержит `1`, если пользователь `i` влияет на пользователя `j`.
