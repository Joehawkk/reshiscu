# Решение задачи №6 — Турнир «Решис!» | Финал. Бизнес и аналитика

Задача оптимального таргетирования рекламы (optimal seeding) на графе из 63 пользователей.

---

## Условие задачи

Компания хочет запустить вирусную рекламу в социальной сети. Пользователь начинает использовать продукт, если это уже сделали **не менее 20% его знакомых**. Нужно выбрать 1–2 человека для рекламного контракта так, чтобы итоговая прибыль компании была максимальной.

| Параметр | Значение |
|----------|----------|
| Бюджет | 5 000 ₽ |
| Доход с одного активного пользователя | 500 ₽ |
| Стоимость контракта | 200 ₽ × количество связей пользователя |
| Порог активации | ≥ 20% активных знакомых |
| Контракты | заключаются только один раз в самом начале |

---

## Стратегия решения

Перебираем всех одиночных пользователей и все возможные пары. Для каждого варианта:

1. Проверяем, вписывается ли стоимость рекламы в бюджет (< 5 000 ₽)
2. Запускаем симуляцию распространения продукта по правилу 20%
3. Считаем итоговое число активных пользователей и умножаем на 500 ₽
4. Из всех вариантов выбираем тот, у которого прибыль наибольшая

---

## Алгоритм распространения

```
Дано: начальное множество seed-пользователей

Повторять пока есть изменения:
    Для каждого неактивного пользователя v:
        если (число активных соседей / число всех соседей) >= 0.2:
            активировать v

Вернуть количество активных пользователей
```
